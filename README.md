本仓库用于课程项目成果展示，提供项目报告以及本地模拟环境演示视频。

### 项目内容

- 员工登录和多模型选择
- 智能对话、文件上传与本地会话记录
- API Key 管理与管理员审核
- Token 用量统计、部门统计及管理后台
- Docker Compose 本地部署，包含模型网关及 DeepSeek/Qwen Mock 服务
